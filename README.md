# Localdream Web UI Studio

**中文** · [English](README.en.md)

面向手机端 **Local Dream**「受控模式」的浏览器图形界面，用于在电脑上完成文生图、图生图、局部重绘与图像超分。

- 单文件 `index.html`，无构建步骤、无前端依赖、无外部 CDN
- 三栏可调布局，宽屏与竖屏各一套排布
- 扩散过程逐帧预览，支持中断
- 生成的图片可自动保存到指定目录，并附带可导入的元数据
- 提供诊断日志导出，便于定位连接问题
- 界面支持中文 / English / Русский 三种语言

| 项目 | 要求 |
|---|---|

| 网络 | 手机与电脑处于同一局域网 |

## 2. 快速开始

```bash
python serve.py --host <手机局域网 IP>
```

启动后访问 <http://127.0.0.1:8777>。设备 IP 也可在页面「设置 → 连接」中修改，改完立即生效。

`serve.py` 同时承担静态服务与反向代理：

| 路径 | 作用 |
|---|---|
| `/` | 提供 `index.html` |
| `/p/8808/*` | 转发至 `http://<手机IP>:8808/*`（控制口） |
| `/p/8081/*` | 转发至 `http://<手机IP>:8081/*`（生成口，含 SSE 与二进制响应） |
| `/api/diag?host=` | 分别探测两个端口的 TCP 可达性 |
| `/api/ping` | 返回启动参数中的默认设备地址 |

常用参数：`--host` 预置设备地址，`--port` 指定端口（默认 8777），`--bind` 指定监听地址（默认 `127.0.0.1`）。

### 必须通过 serve.py 访问

受控模式的两个端口是裸 HTTP 服务，不返回 CORS 响应头。页面若与接口不同源，请求会被浏览器的同源策略拦截；若页面运行于 HTTPS，还会被混合内容策略阻断。`serve.py` 将页面与接口置于同一源，从而规避这两个限制。

**直接双击 `index.html` 无法使用。** 文件协议（`file://`）下 `/p/8808/info` 会被解析为本地路径，请求不会发出，表现为毫秒级的 `Failed to fetch`。页面检测到该情况时会在顶部显示警告条。

| 现象 | 原因 | 处理 |
|---|---|---|
| 日志头部页面地址为 `file:///`，`/p/...` 请求毫秒级失败 | 未通过 `serve.py` 打开 | 用 `serve.py` 启动后访问 `http://127.0.0.1:8777` |
| 请求耗时恰好 8000 ms 后中断 | 设备无响应：IP 变更、跨网段或受控模式被系统回收 | 核对 IP；回到 App 重新进入受控模式 |
| 控制口正常，生成口连接被拒 | 尚未选定模型，8081 未开始监听 | 在页面或 App 中选择一个模型 |

## 3. 设备端准备

受控模式的服务在 `AndroidManifest.xml` 中标记为 `exported="false"`，无法由外部唤起，必须手动开启：

> Local Dream → 模型列表右上角 **⋮** → **设备互联** → 受控模式 → **进入受控模式**

开启后监听两个端口：

| 端口 | 性质 | 提供的接口 |
|---|---|---|
| 8808 | 控制口（JSON） | `GET /info`、`GET /models`、`GET /status`、`POST /select`、`POST /stop` |
| 8081 | 生成口（native） | `POST /generate`（SSE）、`POST /tokenize`、`POST /upscale` |

自检：

```bash
curl -s --max-time 6 http://<手机IP>:8808/info
# {"app":"localdream","protocol":1,"version":"...","device":"..."}
```

设备熄屏或长时间空闲后，系统可能回收后台进程。建议在 App 内开启「纯黑屏幕（保持运行）」，并在系统设置中关闭该应用的电池优化。

## 4. 界面

### 布局

| 视口宽度 | 布局 |
|---|---|
| ≥ 1200 px | 三栏：模型与历史 / 画布 / 参数，两条中缝可拖动调宽，双击复位 |
| < 1200 px | 单列堆叠，顺序为 画布 → 参数 → 模型 |

列宽与其余偏好保存在浏览器本地，刷新后保留。

### 画布

| 操作 | 效果 |
|---|---|
| 滚轮 | 以光标为锚点缩放 |
| 拖拽 | 平移画布（局部重绘模式下改用中键、右键或空格 + 拖拽） |
| 下拉框 | 适应窗口 / 25%–400% |
| 双击 | 在适应窗口与 100% 之间切换 |
| 右上角「图生图」 | 将当前画面按目标尺寸居中裁切后作为图生图底图 |
| 右上角「超分」 | 打开超分面板 |

### 快捷键

| 按键 | 作用 |
|---|---|
| `Ctrl / ⌘ + Enter` | 生成 |
| `Esc` | 取消生成、关闭弹层 |

### 生成参数

| 参数 | 范围 | 说明 |
|---|---|---|
| 步数 | 1 – 60 | 数值可点击直接输入 |
| CFG | 0 – 20 | 小于 1 时负面提示词基本不生效，界面会给出提示 |
| 批次 | 1 – 20 | 连续生成多张，逐张入库并各自计种子 |
| 去噪强度 | 0 – 1 | 仅图生图与局部重绘，步进 0.01 |

### 模型列表

按架构分组，顶部提供筛选：全部 / SD 1.5 / SDXL / DiT / Anima。判定顺序为 `dit_kind` 非空 → DiT，其次 `is_sdxl` → SDXL，其次 `is_anima` → Anima，其余归入 SD 1.5。

### 图生图与局部重绘

- 输入图会按当前目标尺寸做居中裁切后上传，避免后端报 `Img size mismatch`；比例不一致时面板给出提示。
- 「使用当前预览图」可把画布上的图像直接作为底图，无需先保存再上传。
- 局部重绘生成完成后自动切回图生图，避免蒙版覆盖层影响新图预览。

### 结果与历史

生成完成后，结果栏显示种子、尺寸、首步耗时与总耗时。种子可点击复制；提示词单独一行，支持展开与复制。点击历史缩略图可将该图及其参数重新载入画布。

## 5. 设置

设置面板为左侧导航 + 右侧表单，共七个分区：

| 分区 | 内容 |
|---|---|
| 连接 | 实时状态条、连接方式、设备地址与双端口、保存 / 测试连接 |
| 生成 | 默认反向提示词、过程预览开关、预览步幅 |
| 外观 | 语言（中文 / English / Русский）、主题（深色 / OLED 纯黑 / 浅色 / 跟随系统）、强调色与取色、减少动效 |
| 历史 | 缩略图大小、保留上限、占用统计、清空历史 |
| 保存 | 自动保存目录、元数据开关与格式、命名规则 |
| 配置 | 配置导入导出、诊断日志导出 |
| 关于 | 项目地址、运行时信息、接口依据 |

各选项旁的 ⓘ 图标提供说明，悬停或点击展开。

### 自动保存

通过浏览器文件系统访问 API 授权一个目录后，每次生成会自动写入 PNG。可选同时写入同名元数据文件（JSON 或 TXT），也可关闭。文件名由命名规则生成，支持占位符：

`{date}` `{time}` `{seed}` `{model}` `{w}` `{h}` `{index}`

超分结果同样自动保存，文件名追加 `_up` 后缀，且不写入元数据。

### 元数据

JSON 与 TXT 使用同一份字段定义，顺序与取值一致：

```
prompt / negative_prompt / seed / steps / cfg / scheduler / model / width / height / created / generator
```

TXT 为每行 `key: value`。两种格式均可在右栏「元数据」区域导入，回填提示词、种子、步数、CFG、采样器与尺寸；元数据文件也可直接拖入页面。导入不会切换模型，若元数据记录的模型与当前模型不同会给出提示。

第三种格式为 **Local Dream 原生参数**，即 App 内导出的 `_localdream_params` 结构：

```json
{"_localdream_params":true,"v":1,"model_id":"...","prompt":"...","negative_prompt":"...",
 "steps":9,"cfg":1,"seed":1941100032,"scheduler":"lcm","mode":"TXT2IMG"}
```

选择该格式导出后可直接回填到 App；导入时 `mode` 会切换到对应的生成模式（`TXT2IMG` / `IMG2IMG` / `INPAINT`）。右栏「元数据」区域还提供粘贴框，任意格式的元数据粘贴后点「应用元数据」即可，无需保存成文件。

## 6. 接口依据

| 功能 | 接口 | 依据 |
|---|---|---|
| 连接与设备信息 | `GET :8808/info` | 官方 HTTP API 参考；`ld-api` 类型定义 |
| 模型与放大器列表 | `GET :8808/models` | `ld-api` `Module` / `Models` |
| 载入模型并等待就绪 | `POST :8808/select` + 轮询 `GET /status` | `ld-api` `src/device.ts` |
| 后端状态 | `GET :8808/status` | 同上（`idle` / `starting` / `running` / `error`） |
| 生成（SSE） | `POST :8081/generate` | 官方 HTTP API 参考 |
| 提示词 token 计数 | `POST :8081/tokenize` | 官方 HTTP API 参考 |
| 图像超分 | `POST :8081/upscale` | 官方文档未收录，由实测确定，见第 7 节 |

主要参考：

- Local Dream 官方指南 · HTTP API 参考 — <https://ld-guide.chino.icu/zh/features/http-api>
- `@kongxiangyiren/ld-api` — <https://github.com/kongxiangyiren/ld-api>
- 受控模式与双端口说明 — <https://dshpluginhub.ai/zh/plugins/dsh-localdream>

### 实现要点

- `complete` 与 `progress` 事件中的 `image` 为 Base64 编码的原始 RGB 字节（`channels = 3`），需按 `宽 × 高 × 3` 还原后再绘制。
- 进度事件不携带中间帧尺寸，需由字节数反推：先比对当前请求尺寸，再按宽高比推算，最后退回因数分解。
- `seed` 省略表示随机；传入 `-1` 会被当作固定种子 `4294967295`，因此留空时不发送该字段。
- `cfg = 1.0` 会跳过无条件 UNet 计算，此时反向提示词不生效。
- 部分后端（DiT / Anima）不按 CLIP 计数，`/tokenize` 返回 `max_length = 0`，表示不限制长度。

## 7. 图像超分接口

官方文档未收录该接口，协议由逐层试探确定：

```
POST http://<手机IP>:8081/upscale
Content-Type: application/octet-stream
X-Image-Width: <宽>
X-Image-Height: <高>
X-Upscaler-Path: <放大器路径>

<原始 RGB24 字节，长度必须等于 宽 × 高 × 3>
```

- 响应为 `image/jpeg`，放大倍率固定为 **×4**，`X-Scale` 一类请求头无效。
- 请求体必须是原始 RGB，传入 PNG / JPEG 会返回 `Image data size mismatch`。
- 放大器路径取自 `GET :8808/models` 的 `upscalers[].path`；设备未安装对应放大器时该字段为空。
- 倍率中的 2× / 3× 由 ×4 结果在浏览器端降采样得到。
- 执行过程中画布底部显示进度指示与已用时间；输出像素超过约 8 MP 或单边超过 4096 时，需二次确认。

## 8. 已知限制

- **8081 仅在选定模型后监听。** `state` 为 `idle` 时生成口不可连接，属正常状态。
- **`state` 变为 `running` 后仍有数百毫秒的空窗期。** 客户端在载入模型后会主动探活至可用，生成时遇到网络错误也会等待重试一次。
- **尺寸字段的含义随模型族不同**（实测 3.0.0-alpha.7）：

  | 模型族 | 生效字段 | 备注 |
  |---|---|---|
  | SD 1.5 | `width` / `height` | `aspect_ratio` 被忽略；`resolutions` 仅为预设，非硬约束 |
  | SDXL | `aspect_ratio` | `width` / `height` 被忽略 |
  | DiT | `width` / `height` | `aspect_ratio` 被忽略 |

- **直连模式受限。** 自定义请求头会触发跨域预检，设备仅允许 `Content-Type` 与 `Authorization`，因此超分需经同源代理。直连模式下若检测到本地服务可用，超分会自动改走代理。
- **未接入 UltraFix（分块重绘）。** 该能力仅部分后端支持，且未收录于官方接口文档。
- **局部重绘蒙版为白底区域语义**（白色为重绘区）。官方未规定极性，若后端相反需调整 `exportMaskB64()` 中的判定。
- **同一时间只允许一个生成任务。** 设备算力有限，生成中按钮切换为取消。

## 9. 配置与存储

| 内容 | 位置 |
|---|---|
| 界面与生成偏好 | `localStorage`，键 `ldstudio.config.v1` |
| 自动保存目录句柄 | IndexedDB，库 `ldstudio`，表 `kv` |
| 诊断日志 | 内存，最多 800 条，可导出 |

诊断日志记录每次请求的方法、路径、状态码与耗时，以及连接、载入模型、生成、超分等事件和页面异常。导出文件包含页面地址、连接方式、设备型号与版本、当前模型与画布尺寸，可直接用于问题定位。
